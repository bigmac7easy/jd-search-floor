
# JD Search Floor

QGIS 실내공간정보 층별 조회 플러그인

## 프로젝트 소개

실내공간정보 데이터의 층별 조회 및 편집 편의성을 향상하기 위한 QGIS 플러그인입니다.

여러 레이어의 `FLR_NO` 속성을 기반으로 필터를 일괄 적용하여, 원하는 층의 공간정보를 편리하게 조회할 수 있습니다.

## 주요 기능

- 상층 이동 (Floor Up)
- 하층 이동 (Floor Down)
- 현재 조회 층 표시
- 층별 필터 초기화 (Reset)
- 다중 벡터 레이어 일괄 필터링
- 문자형 및 숫자형 층 정보 자동 판별

## 개발 환경

- QGIS 3.x
- Python 3
- PyQGIS
- PyQt
- Visual Studio Code

## 설치 방법

1. 저장소의 소스코드를 다운로드합니다.
2. 플러그인 폴더를 QGIS 플러그인 경로에 복사합니다.
3. QGIS를 실행합니다.
4. 플러그인 관리자에서 JD Search Floor를 활성화합니다.

## 사용 방법

1. 실내공간정보 레이어를 QGIS에 추가합니다.
2. JD Search Floor 도구 모음을 활성화합니다.
3. 상층·하층 이동 버튼으로 원하는 층을 조회합니다.
4. Reset 버튼으로 층별 필터를 초기화합니다.

## 데이터 요구사항

- QGIS 벡터 레이어
- 층 정보를 포함하는 `FLR_NO` 필드
